## 空间语义（INDEX 短板修正，本卡构图裁决）

huashu 28 的 INDEX 短板是「墙是池水、地是木头的空间别扭」（室内墙=池水壁画 + 地板=暖木，语义冲突）。本卡**改构图**：全画即户外睡莲池正视——顶冠叶幕（垂柳枝条）→ 远岸树荫带（波状边界垂舌入水）→ 日本桥拱（landing 在左右岸堤）→ 开阔水面（睡莲丛/天光倒影/涟漪）→ 前景岸墩（芦苇）。无室内墙面/地板，空间语义先行；帧差验收按沸/静分窗（见 QC 豁免档），静档结构区 swap 对 0.0% 为证。

## 锁死项（签名逐条）

- **签名①短横笔水面 + 160 根光斑颤动**：
  - 水面遍 `cell 9 / len 34 / width 6.5 / angle≈0±0.06`（`0.04·sin(y·0.05+x·0.004)+0.03·noise`）、jitterCol 14、`boil: 6`、outline 0（印象派不勾边）；
  - 光斑颤动群（motion.ts drawLightDabs）：160 根亮色横短笔（`#fffbe8 #fdf0d0 #f8e0ec #e8f4ff`），亮度 `clamp(sin(t·(5..11)+φ)·sin(2.3t+i))` 双正弦截断，**10fps 横向跳 ±3px**（配方 ±5px 按帧差预算收敛，颤动语义保留），α≤0.8·(1+0.35e)，source-over（浅水底 screen 物理不可见，08 踩坑回流），岸区不落斑、叶幕内减密。
- **签名②boil 分档纪律**（08 教训在「分档」上的应用——全屏 6fps 沸腾=帧差 47% 满屏噪声）：
  - 水面 boil 6（沸）｜叶幕+远岸树荫 boil 6（植物区活）｜**岸堤 boil 0**（静，配方地板档的空间映射）｜**桥体结构 boil 0**（笃定，配方窗框档的空间映射——建筑结构不随水沸）；
  - **烘焙实现**：`scripts/bake_paint.mjs` 渲 6 态 = boilSeed 0..5（沸档逐态换种子、静档各态相同），正片 `idx=floor((f-1)/5)%6` 换图 = **恰 6fps 沸腾，与 boil:6 实时渲染等价且确定性**（一个沸循环=1s=30f=6 态×5f）；
  - 量化铁证：静档结构区 crop（岸墩内部）在**所有邻帧对（含 swap 对）帧差 0.0%**，6 张烘焙位图该区互差 0 像素；沸区 swap 对 42% 即签名本体。
- **签名③桥独立成层 + 深色树荫衬底 `#24452a` 系**（「主体先铺深衬底再描亮线」通用纪律）：
  - 底稿先铺全宽远岸树荫带（`#2a4a30→#223f2a`，噪声波状上下缘垂舌入水），桥层再铺一圈更深衬底条 `rgba(31,56,38,.92)`，桥亮线才不被叶色板吞掉；
  - 桥体：绿色拱 `#3f8a62` 粗线 20px + 扶手亮线 `#8fdcae` 8px + 中栏 + 竖栏，独立 canvas 层最后叠加；
  - 桥层 source-atop 细笔 `cell 5 / len 10 / w 4 / boil 0`（结构笃定档），palette 桥 5 色混底 0.3（用不用=亮度纯函数 `col[1]>140 && col[0]<170`，恰 1 随机数——stable 契约）。
- **签名④睡莲漂 + 柳影波动 + 涟漪虚线椭圆外扩**（母题运动层，热帧矢量重画）：
  - 睡莲：10 丛约 100 片缺口椭圆（rx 30-62 / ry 10-17，40% 粉/白花），漂移 `x+sin(1.3t+φ)·7+5t` + 叶面高光弧两笔（矢量层的笔触质感补偿）；
  - 柳影：5 条竖带（配方 5 条布局缩放），边缘 `sin(0.03y−3.2t+k)·14` 横向波动 + 带内柳色横笔；
  - 涟漪：3 处同心虚线椭圆（`ry=rx·0.22`，dash [12,10]）外扩并淡出，hero 期加 2 处、环径加强（「涟漪荡开」）；
  - 紫藤：12 串垂花**点列**（每串 9 点由大到小，`sin(2.4t+0.9i)·8` 摆——粗线=药丸坑，配方踩坑回流）；桥倒影绿弧波动；天光倒影 4 片缓漂。
- **签名⑤色彩阴影**（印象派光色，比灰阶阴影高一档）：桥层 source-atop 线性渐变——受光侧叠暖黄 `rgba(255,236,170,.22)`、背光侧叠紫 `rgba(110,100,190,.32)`（(140,240)→(1140,420)）。
- **签名⑥ripple 转场**（水波语义转场，f199-225 进 hero）：
  - 旧画：6px 行条横向正弦错位 `dx=sin(y·0.045−p·26)·46·sin(π·min(1,p·1.2))·(0.4+d)`（倒影被搅，幅度先增后收）；
  - 新画：3600 根横笔椭圆（seed 41，`d=hypot(x−cx,(y−cy)·1.9)/1700+r·0.06`）按椭圆距离荡开，`front=ease.inOut(p)·1.15−0.05`，clip 显影；
  - 涟漪前沿 3 圈浅色虚线椭圆（dash 流动 `lineDashOffset=−p·300`）+ 140 根水光短横线闪 + p>0.7 新画整体显影兜底。
- **区域色板 token（配方 28 锁死，mixBase 0.35-0.5 保明暗，禁改色值）**：
  - 水 9 色 `#5b6fb5 #7d8fd0 #9db5e0 #6aa0a8 #b7a6d8 #d9c8e8 #8fb8a8 #a6c4e8 #c8b0d8`（0.5）
  - 叶 6 色 `#5f8f4a #7fae5a #3f6f4a #9cc070 #6f9a7a #b4cc78`（0.4）｜粉 4 色 `#f0a0b8 #f7d0dc #fff2f4 #e88aa0`
  - 柳 5 色 `#3f6a58 #557a4a #2e5048 #6a5f9a #4a6aa0`｜岸 6 色 `#c69a6a #b07a5a #d8b08a #9a6a7a #8a7aa8 #e0bc90`
  - 树荫 5 色（配方深绿族）`#2f5a30 #3a6a5a #24452a #2e5048 #557a4a`｜桥 5 色 `#8fdcae #a8e8c0 #6fc49a #c0f0d0 #7fb8d8`
  - 区域路由按坐标分发（不吃随机数），swatch 抽色恰 1 个随机数，stable 兜底永不 null。
- **方向场分区**：叶幕上垂笔（−0.95±0.34noise+微摆）/叶幕下横笔/远岸近水平/岸堤 0.08+0.12noise（配方地板场）/水面横笔 ≈0±0.06——**禁全域单值方向场**。
- **性能纪律**：底稿+四遍 boil 分档笔触+桥层按烘焙态预渲染为静态位图（6 态，bake_paint.mjs），热帧 = drawImage(烘焙位图) + drawMotion 矢量层（~700 path ops），单 canvas；**Bench 实测 3.86ms/热帧**（n=90，getImageData 强制同步计 GPU）。禁 Math.random/Date/网络。
- **版式**：藕紫纸片（`rgba(250,248,242,.94)`）+ 水墨蓝字（`#3d4d86`）+ 藕粉弧线 + hash 微转角字幕卡；水汽紫罗兰暗角常驻。
- **确定性**：mulberry32 + 格点 hash2 + 解析 noise2d/sin；mulberry32 状态均为函数内局部变量（amphora 闭包坑已排查）。

## 复用适配点

- **boil 分档 + 烘焙态轮换**：`6 态 = boilSeed 0..5`、`idx=floor((f-1)/5)%N` 的「恰 N fps 沸腾」烘焙法——一切「局部沸腾」风格（手绘线沸腾/粉彩/蜡笔）的通用实现，比实时渲染便宜一个量级且逐帧确定；静档结构区帧差 0.0% 的分档量化口径可直接复用。
- **swap/steady 分窗帧差口径**（`frame_diff_boil.py`）：一切「planned diff」（步进/沸腾/闪切）风格的防频闪验收框架——稳态对判 <2% 防频闪线，swap 对按签名语义登记（rubberhose 步进先例的形式化）。
- **「结构 boil 0」映射纪律**：配方分档档位（地板/窗框静档）按空间语义映射到新构图（岸堤/桥体）—— boiling 系风格里「人造物与大地不沸，水与植物沸」的通用判断式。
- **桥深衬底三明治**（深衬底带→衬底条→亮线）：一切「细亮结构浮在花背景上」的主体保护法（栏杆/线缆/枝条/高光边通用）。
- **ripple 转场**：水波语义转场（水相关题材全可用），TS 重写件在 kit.tsx 可直接搬（3600 椭圆 clip 荡开 + 行条错位 + 虚线前沿）。
- **色彩阴影 source-atop 双向渐变**：印象派系卡的角色/主体光色通用件（受光暖黄/背光紫，参数 α.22/.32）。

## 与近邻卡的边界（同库不同参声明，油画族 strokes.ts 底座四卡）

- **lily-pond ≠ swirl-oil（梵高，同库标杆）**：swirl-oil 长笔（len 22-64）+ 深蓝描边（outline 0.8-0.9）+ 漩涡方向场 + 全卡 8fps boil；lily-pond **短横笔水面（len 34 水平 ±0.06）+ 零描边 + 分区方向场 + boil 分档（仅水/叶 6fps，结构 0）**。域：表现主义「笔触即造型」vs 印象派「水面的光颤」。
- **lily-pond ≠ light-dabs（印象派光斑，同族最近邻）**：light-dabs 室内看花园（窗景+光斑）构图、**boil:0 笔触位置钉死**（08 教训的全量解——位置永不重洗），34 斑桌面/地面光斑；lily-pond 户外全池构图、**boil 分档**（水面真沸腾=28 号配方本体），160 根水面颤动斑 + 睡莲/桥/柳影母题。同「光斑双正弦截断」语义，但 light-dabs 的活来自斑的明灭漂移、lily-pond 的活来自笔触沸腾+水面母题运动——两个「印象派怎么动」的答案。
- **lily-pond ≠ sfumato**：sfumato 零可见笔触（blur 罩层做旧）；lily-pond 笔触即水面本体。
- **lily-pond ≠ scream-warp**：蒙克长笔扭曲场高透表现焦虑（不描边/更长/更透的刻意分化）；lily-pond 短横笔高调外光表现愉悦水光。

## QC 豁免档

- **swap 对峰值 42%（沸档区）**：签名沸腾语义（水面/叶幕 boil 6fps 烘焙轮换），**rubberhose 步进帧差豁免同型**——style 本体要求 planned diff；静档结构区 swap 对 0.0% 证明噪声不越界。防频闪口径=稳态对窗口：定帧段 f340-374 peak 1.810%、SC02 尾 f110-115 peak 1.833%、SC04 尾 f275-280 peak 1.866%，全 <2%。
- **f189-190 帧差 3.14%**：字幕块「柳影在水里晃」三帧退场（f189-192），局部 UI 转场非笔触频闪（light-dabs f95-96 字幕退场豁免同型）。
- **f141-168 稳态对 peak 7.6%**：SC03 推近曲线最陡段（outC 中段 ~0.17%/帧全画面亚像素平移），相机运动语义；相机落定窗（f110-115/f275-280）全 <2%。
- **f12-17 帧差 96%**：画布罩淡出全画显影（「未落笔→落笔」叙事本体，f1 罩 0.97 隐透，probe_blank 19 帧全绿佐证非空屏）。
- **f116-117 / f280-281 帧差 63-66%**：镜头缝相机 origin 跳变硬切（50/55→50/72→50/40），句边界转场语义。
- **f199-225 帧差 58-61%**：ripple 转场行条错位+荡开本体（签名⑥）。
- **f375-380 收暗 0.35**：合法收尾非黑场。
- **笔触边界串色**：paintStrokes mask 只判笔触中心，沸档笔触可越过分区边界伸入静档 ≤len/2+cell/2（配方同款行为，分区软边=油画罩染感）；静档内部（深于 25px）不受影响（结构区 crop 实测 0.0%）。
