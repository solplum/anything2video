# SPEC：印象派光斑短笔触（light-dabs）

> **本仓复用更新（2026-10-19）**：本目录 `strokes.ts` 现在保留为兼容入口，唯一实现位于 `../shared/paint/strokes.ts`。新手动复制必须带上共享兄弟目录，布局见 [共享代码说明](../shared/README.md)；下文 `samples-v4/` 是历史源工程记录，旧包外工程中的完整副本不受影响。

**正本源工程**：`samples-v4/light-dabs`（2026-10-08 验证交付）｜**图元库**：工程 `src/style/strokes.ts`（流场笔触渲染器，与共享正本逐字节一致）+ `src/style/world.ts`（底稿/两遍分区笔触/方向场/区域色板/烘焙缓存）+ `src/style/actors.ts`（少女/猫/角色细笔触/五官线）+ `src/style/motion.ts`（光斑/罂粟/云/猫尾/帘缘微光运动层）+ `src/style/kit.tsx`（PaintCanvas 烘焙态轮换 + React 信息层）；**共享正本**：`samples-v4/shared/paint/strokes.ts`（油画族共用，本工程拷用件经 diff 核实与正本一致）
**风格句**：两遍分区笔触（主画面粗笔＋窗景细笔）+ 方向场分区摇曳 + 光斑「双正弦截断」明灭 + 笔触位置固定不沸腾——「印象派=光斑短笔触：画的是光落在东西上那一秒」。
**技法借鉴** huashu-art-motion `lib/paint.js` P.strokes/P.swatch + `scenes/08_impressionism.js`（206 行，MIT, alchaincyf），TS 重写——机制与参数级借鉴（抖动网格取底稿色/区域色板混底/两遍分区参数/方向场分区/stable 防重洗契约/双正弦截断光斑/角色 source-atop 细笔），结构、命名、API 全部按 Remotion/TS 惯用法重写，零代码拷贝。借鉴登记：`技法借鉴 huashu-art-motion 08_impressionism (MIT, alchaincyf), TS 重写`。

## 锁死项（签名逐条）

- **签名①两遍分区笔触**（同一参数跑全图=地毯，必须分区两遍）：
  - 主画面粗笔：`cell 11 / len 20 / width 7 / jitterCol 26`，`mask = !fineZone(x,y)`（窗景+《日出》取反）；
  - 窗景细笔：`cell 6 / len 11 / width 4.5`，`mask = fineZone`（窗洞 WX0-248/WX1-527/WY0-88/WY1-365 ∪ 墙上《日出》框）。
  - 两遍 `outline: 0`（印象派不勾轮廓，与梵高的深描边区分）、`boil: 0`（笔触位置固定）、seed 12/13 恒定。
- **签名②方向场分区**（`world.ts angleField`，t 为烘焙态冻结的方向场时间项）：墙向右上斜（阳光区 `x>667,y<347` 取 -0.95，其余 -0.55）± 0.55·noise + 0.35t 火苗摇曳项｜地面近水平（0.12·noise − 0.05）｜窗帘与桌布竖向（−π/2±微噪）｜盆栽从盆心放射（atan2 + 摇曳）｜《日出》横向水波（0.03·sin(y·0.45)）｜窗内天空横向、窗内花草随风轻转。**禁把方向场写成全域单值**——分区笔向是本卡的「画风骨架」。
- **签名③光斑双正弦截断明灭**（`motion.ts drawLightPatches`，34 斑=7 桌面+27 地面）：
  - 节奏：`k = 0.5 + 0.5·sin(t·sp+φ)·sin(t·sp·0.53+2φ)` → `a = clamp(k·1.3−0.15)`——双正弦拍使亮灭节奏不规则（单正弦=呼吸灯，一眼假）；
  - 合成：**source-over，α ≤ 0.95**——配方踩坑回流：粉彩底上 `screen` 物理不可见，禁改 screen；
  - 斑内 26 笔亮黄白短笔，`mulberry32(seed·31)` 种子固定，只整体横漂（dx=sin(t·2.6+φ)·18·(1+1.2e)）＋明灭——斑内笔不重洗；
  - 避让：CAT_BOX 与少女裙摆落区 GIRL_LOW 不落斑。
- **签名④角色 source-atop 细笔只补五官**（`actors.ts charStrokes`）：
  - 角色平涂 → 同层 `source-atop` 细笔 `cell 7 / lineWidth 4.5 / len 13×(0.7+0.6h)`，只画 α≥200 的角色内部（背景零污染）；
  - **不勾轮廓，只补五官**：五官线（淡紫眉线/蓝瞳点/唇）由 `drawGirlFeatures` 热帧每帧矢量补画（含周期眨眼）；角色本体零描边；
  - **INDEX 短板修正（脸和手被笔触打碎）**：脸部椭圆（GIRL_FACE 12.5×15）与双手圆（r=9）**完全跳格不上笔**；白裙/白吻部走 `col>(240,236,225)` 保白判定混回白（四色白微抖），禁刷花；
  - 随机数契约：每格用 `hash(格号)`（纯函数无状态），与是否落笔无关——猫尾/呼吸一动只有那一格的笔变，不整层重洗。
- **签名⑤笔触位置固定、方向场连续摇曳**（「活而不闪」范式，huashu 经验第 13 条）：
  - 烘焙 8 态（`scripts/bake_paint.mjs` 从 Bake 合成渲出 8 张确定性 PNG）共用同一笔触种子（seed12/13，boil:0），只冻结方向场时间项 `t=(i+0.5)·0.1`——stable 契约下随机流恒定，逐格 px/py/palette/len 完全一致，态间只有笔向小步转动；
  - kit.tsx `PINGPONG [0..7..1]` 轮换（≈0.27s/态）消 7→0 绕回跳变；
  - 「活」由运动层承担：光斑漂移明灭/罂粟摇（茎底不动花头摆）/云走（30px/s，hero×2.5）/猫尾贝塞尔甩/帘缘微光/盆栽顶花摆/茶壶热气/少女眨眼。
- **签名⑥stable() 防重洗为共享渲染器默认行为**（08_impressionism v2 频闪事故的解法本体，`strokes.ts` 库级纪律）：
  - 一切 palette 过 `stable()`：每格恰好消费固定个数随机数（swatch=1 个）、永不返回 null（null 回落底稿色）；
  - 「这格要不要用区域色」判定只允许零随机数纯函数：区域路由/亮度阈值/色相判定（红屋顶 `col[0]>180 && col[1]<90`、白窗框 `col>(240,236,225)`、绿植 `col[1]>col[0]`）；
  - paintStrokes 主循环随机数顺序契约：px/py 2 个 → palette 1 个 → 长度 1 个，恒定个数；
  - **红线：palette 内「条件多吃随机数」（如高光格提前 return 不抽色）= 频闪事故复辟，禁**。
- **区域色板 token（配方 08 锁死，mixBase 0.3–0.45 保明暗，禁改色值）**：
  - 粉紫墙系 9 色 `#f3c6d2 #e8b6dc #f6dcc0 #d8c0ec #fbe8b0 #f0a8c0 #c8b8f0 #fff2d8 #e8c8f0`（0.35）
  - 奶黄阳光 7 色 `#fff0b0 #fbe08a #ffe8c8 #f8d0d8 #fff8e0 #f0c0d8 #e8d0f8`（0.3）
  - 玫瑰橙紫地面 7 色 `#e8a090 #d88aa0 #f0b890 #c890b8 #f6c8a0 #b0a0d8 #e89880`（0.4）
  - 扩展：窗内天空 5 色（0.4）/窗内绿 6 色（0.4）/窗帘淡紫 5 色（0.35）/桌布 6 色（0.45）
- **性能纪律**：底稿+两遍分区笔触+角色层按烘焙态预渲染为静态位图（8 态，Bake 合成），热帧 = drawImage(烘焙位图) + drawMotion 矢量层，单 canvas；模块级 Image 缓存 + delayRender 预载。禁 Math.random/Date/网络。
- **版式**：米白纸片（`rgba(252,246,238,.94)`）+ 玫瑰墨字（`#6a3a58`）+ 玫瑰粉手绘弧线（SVG path）+ hash 微转角字幕卡；暗角暖玫瑰调常驻。
- **确定性**：mulberry32 + 格号 hash + 解析 noise2d/sin；mulberry32 状态为函数内局部变量（amphora 闭包坑已排查）。

## 复用适配点

- **stable() 防重洗包装**（`strokes.ts`）：一切「底稿会动＋渲染器按格取色」的场景的默认行为——已进共享正本 `shared/paint/strokes.ts`，油画族四卡共用；任何新「按格取色」渲染器（蜡笔/粉彩/织毯）直接继承该契约。
- **两遍分区笔触参数表**（粗底 cell11/len20/w7 + 细节区 cell6/len11/w4.5）：一切「画面里还有画面」（窗景/挂画/镜面/屏幕）题材的通用配方，细笔区用 `mask` 路由而非独立渲染器。
- **方向场分区写法**（angleField 单函数内 if 分区）：「每样东西笔往哪边长」的可读性骨架，花卉/织物/地形题材直接改分区表。
- **LightPatch 双正弦截断光斑**：水面波光/树影光斑/烛光摇曳通用件，改 sp/φ 与斑形即可；记死 source-over α≤0.95 于浅底。
- **角色 hash(格号) 独立随机契约**：一切「会动的角色 + 按格笔触」的组合（gouache 人物/彩绘陶俑）防整层重洗。
- 烘焙态 PINGPONG 轮换：任何「位置固定 + 微摇曳」的循环动效通用方案（替代 boil 的不闪变体）。

## 与近邻卡的边界（同库不同参声明，油画族 strokes.ts 底座）

- **light-dabs ≠ swirl-oil（梵高，同库标杆）**：同一 paintStrokes 底座、参数预设两极——swirl-oil **长笔**（len22-64）+ **深蓝描边**（outline 0.8-0.9）+ 三遍分区 + 漩涡方向场 + 8fps boil 换种子（笔触位置跳）；light-dabs **短笔**（len11-20）+ **零描边** + 两遍分区 + 分区直线/放射方向场 + boil:0（笔触位置固定，只有方向场摇）。域：后印象派表现主义「笔触即造型」vs 印象派外光写生「光斑即主体」。
- **light-dabs ≠ scream-warp（蒙克，同库）**：蒙克不描边/更长/更透的「刻意分化」纪律（波浪长笔+扭曲场+高透叠色表现焦虑）；light-dabs 短促碎笔+粉彩高调+光斑明灭表现愉悦外光。同「不描边」但笔长差 3-5 倍、色明度差一档。
- **light-dabs ≠ sfumato**：sfumato 零可见笔触（blur 两遍+罩层做旧，笔触消隐）；light-dabs 笔触即画面本体。
- **light-dabs ≠ lily-pond（莫奈睡莲，同题材族）**：lily-pond 管户外水面母题（睡莲/倒影），light-dabs 管室内看花园的「窗景+光斑」构图；同用 stable 底座，方向场与色板各自锁死。

## QC 豁免档

- **f95-96 帧差 3.055%（>2% 线，已定界非缺陷）**：峰值对在字幕块 1 三帧退场窗（subs.ts `to:98`，退场 f95-98，模板 CaptionCard 惯例 3 帧出）——局部 UI 转场，非笔触频闪。防频闪验收口径（笔触本体）：定帧段 f333-363 peak 1.663% + S02 笔触窗 f60-94 peak 1.679%，两窗全 <2%。字幕大面积淡出必然产生 2-4% 局部帧差（sfumato 全片 max 9.938% 同源），修法则毁模板字幕惯例，不修。
- 两个镜头缝硬切（f179-180 帧差 66.8% / f268-269 63.1%）：SC03→SC04→SC05 相机 transform-origin 跳变（72%/40%→38%/52%→50%/55%），句边界硬切转场语义，非闪帧。
- f330-366 定帧 1.2s：构图冻结但光斑明灭/罂粟摇/云走/猫尾/烘焙态轮换不停（probe_liveness SC05 相邻 MAD 2.336-4.045），合法微动非全静止。
- f1 画布罩 0.97：「未落笔的画布」叙事本体，场景隐透（probe_blank 25 帧全绿佐证），非空屏。
- 末 6 帧收暗 0.35（f364-369 帧差 87-92% 坡）：合法收尾非黑场。
- BGM `--style` slug 中断前记录缺失：seed 20261106 文件 + sha256 链 + 响度实测可证定盘正确性；slug 值待主控 STYLE_MAP 登记链核补（不阻塞成片与卡技术验收）。
