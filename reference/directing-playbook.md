# 导演手册

质量来自观众能理解的状态变化、真实的质感与节奏。技术门禁负责工程正确，导演决策负责画面成立。

## 定方向

在 research/creative-brief.md 写：受众与一个学习目标、看完能做的动作、最重要的事实、贯穿示例、画幅、语气、主角、首尾关系。选参考时记录具体时间段与可借的方法；只有实际查看过的媒体才算参考证据，制作模型和官方归属单独核实。

对陌生风格或方向未定的项目，用同一段已确认文案、同一目标画幅实渲染两个方向；构图、字体层级、色彩关系、运动语法都应不同，不能只换强调色。开场、复杂中段、结尾各看关键帧，再看一段真实运动。已验证 SKU 沿用时做同内容样张回归，记录沿用依据，不重开用户已定的套餐选择。证据格式与现有 check-plan / visual 审核的接线见 [视觉方向打样](visual-direction.md)。

## 把一句话变成镜头

每镜头写清：观众此时的问题、开始状态、触发动作、结束状态、唯一焦点、与下一镜头的承接，以及此刻要产生的感受（疑问、理解、惊讶、安心等）。purpose 说明要理解什么，action 说明真的发生什么，result 说明变化证明了什么；不能以效果名字替代观众所得。

在分镜里记录 `direction: {mode, focalPoint, viewerTakeaway, emotion, timing, holdReason?, cutReason?}`。`timing` 说明哪个词/拍触发动作、何时到位、观众还需多久读完；有意静止与硬切写理由和时窗。这里只补充原有 purpose/action 与 beat sheet，不另造一份时间轴。无声片用阅读/动作时长，不能伪称已验证声画同步。

例如“缓存能减少重复计算”：同一请求第一次穿过计算器得到结果并存入缓存，第二次走缓存短路；两条路径保留同一请求标识与计时单位。不要仅显示“快、稳、省”三个标题。

软件教程要展示能照做的步骤、文件位置、正确结果和失败时的修复。真实UI可用经授权的截图或录屏；简化示意标明示意，不能画出不存在的功能。命令按语义切段，给足阅读时间。

不要用一排空描边框假装代码或表格内容。应显示有意义的 token、数值、对象或状态变化；确需空槽时明确其含义并演示填入、清空或容量变化。空态图可以成立，缺少内容的占位装饰不能承担教学。

## 选择表现形式

| 信息任务 | 适合的画面 |
|---|---|
| 因果/流程 | 输入对象被处理并形成输出，保留身份与方向 |
| 比较 | 同一变量、同一尺度、同一观察时段，结论由变化得出 |
| 数量/数据 | 标明单位、来源、轴和示意性质，避免无依据计数 |
| 空间/结构 | 从整体到局部，遮挡与层级能说明关系 |
| 历史/谱系 | 清楚的年代定位、跨章联系、行动中的贯穿符号 |
| 操作教学 | 起始条件、实际操作、产物、一次失败与修复 |

抽象信息优先代码；有机材质、真实人物和产品细节优先可信素材或合格生成资产。材质不能遮住解释，也不能用不相干器物给软件教程增加电影感。

## 物理机械隐喻法则（The Object is the Explanation，借鉴 Anatomy，MIT）

**物体本身就是解释**，适用于机械关系确实有助于理解的镜头，尤其 isometric-anatomy。抽象技术也可以用数据流、真实 UI 或简洁图解；关键是让状态变化解释机制，不能只把术语放进方框。采用物理隐喻时明确它是示意，不把发明的仪器说成真实设备，不为零件复杂度牺牲知识准确性。以下工艺规则限于选用该路线的镜头。

### 1. 经典抽象概念映射词典

| 抽象概念 | 物理机械实体 | 机制如何解释概念 |
|---|---|---|
| **速率限制（Token Bucket / Leaky Bucket）** | 进水料斗、浮球连杆阀、分拣漏管与步进轮 | 滴入速率固定，料斗满溢则下落滑板弹出拒绝信号 |
| **共享资源复用（GPU Context / 连接池）** | 龙门三轴绘图仪（Gantry Plotter）或分拣机械臂 | 单一机械臂滑轨移动，依次访问 16 个工位储液槽 |
| **缓存击中与未命中（Cache Hit/Miss）** | 弹子锁（Pin-Tumbler Lock）与离合齿轮 | 每一位 pin 高度完全对齐时锁芯瞬间旋开短路直通，否则落入备用棘轮重算 |
| **可分离高斯模糊（Separable Blur）** | 正交双滑轨钢梳与微孔印章 | 一组梳齿沿 X 轴梳理，第二组沿 Y 轴二次刮抹，效率提升 49×49 $\rightarrow$ 49+49 |
| **读写锁 / 信号量（RWLock / Semaphore）** | 多齿凸轮轴与双向互锁插销 | 读插销并行滑入多个浅槽；写插销降下时将主凸轮抱死 |
| **零拷贝数据流（Zero-Copy DMA）** | 气动穿梭管道与磁吸悬浮导轨 | 数据包不经中转箱倒手，直接沿主导轨无摩擦滑入目标料斗 |

### 2. 机械实体工艺五铁律

1. **零件致密（40+ 零件原则）**：一台仪器包含底座（Base Plate 带地脚与槽螺丝）、结构立柱与滑轨（Rails & Stops）、驱动机构（Carriage、Bushings、弹簧）、管线回路（带法兰与卡箍）以及唯一发光/焦点零件（Lit Subject）。
2. **两级审阅视感**：1x 视距下是一台轮廓清晰的完整仪器；4x 局部微距特写下，每一个螺栓、倒角、刻度、轴套与焊缝都真实存在、令人赏心悦目。
3. **线头严禁浮空**：所有刻线、凹槽、加强筋必须落在零件外轮廓或圆点上，严禁悬空在空白表面（由 `probe_line_ends` 自动化门禁拦截）。
4. **管道严禁穿透**：管线之间、管线与零件之间必须保持物理间隙；管道必须发自法兰或端口，终于阀门或端子，严禁从半空冒出。
5. **动态阻尼与读数同频**：零件位移使用带阻尼的弹簧（`dampedSettle`）或真实刚体冲程，仪器上的千分表（Dial Gauge）与数字滚轮（DigitRoll）实时反映物理位移数值。


## 构图与运动

一屏一个主要注意目标，其他元素提供条件和结果。优先原生画幅、安全区、文字可读性与真实主体比例。光、粒子、纹理、glitch、相机都按镜头目的选，不作为每镜必填装饰。

有力量的动作包含预备、接触和回稳；解释路径使用连续身份与方向。层间错相用于引导注意，同步动作在比较、齐发、同因果事件中可以成立。相机靠近是为了看清局部，不为凑次数。HUD和字幕保持屏幕空间可读。

停留时间从实际样音、阅读和动作完成测得。复杂屏先减信息再延长；不能靠恒定微动假装内容活跃。有意静止、硬切、纯色与留白可以成立，要在分镜记录目的。反同质化只改变能服务主题的维度，不强迫连续五项全部换掉。

全片节拍骨架按秒写进 `research/beat-sheet.json`：钩子 0.5s 内出现（禁 0.3s 以上空场/黑场开场）、hero moment 通常放在 60–75%，因叙事调整时写明理由、结尾定帧以 0.8–1.2s 为起点，按实际阅读需要延长，可有意静止。beat sheet 是音画同读的创作正本（与实测 beat_grid 的分工见统一生产契约），先于建组定稿；音乐提名（曲库与程序编曲两通道）与 SFX 钉帧都从它取落点。

## 动效四段律与介质法则（v5.0.0，方法论吸收 mg-styles-15 / xilo-opus-video / huashu-art-motion / dashi-animationstyle）

### 1. 动效四段律（4-Phase Motion Protocol）

四段是设计动作的检查框架，不是每镜必须塞满的效果配额：
1. **进场（Entrance）**：先建立唯一焦点。直接切入已成立的构图也合法；弹性/过冲只用于适合的材质与情绪。
2. **主动作（Primary Action）**：解释状态变化，关键接触、显现或结果对齐解说词/拍点。需要回稳才用阻尼，读数不被弹跳拖迟。
3. **停留（Hold）**：给观众理解、阅读或感受的时间。可静止，也可有次要环境运动；后者不能抢走主焦点，不能用粒子冒充教学内容。
4. **出场（Exit / Transition）**：按叙事关系决定承接、硬切、匹配切或介质转场。切点服务因果/对比/情绪，不能只为“每镜有转场”。

先在 creative-brief 选主运动语法，镜头可有理由地变奏：

| 语法 | 适合任务与常见配方 | 停留与切换决策 |
|---|---|---|
| continuous | explainer 的机制演示、epic 的连续世界、documentary 的空间观察 | 保留对象身份、方向与状态；动作未完成不切，阅读时允许停机；微动只在世界需要时保留 |
| montage | promo 的对比/冲击、documentary 的跨时空证据、章节压缩 | 有意硬切在语义或声音落点发生；新镜及时重建焦点与时间地点，不用过渡抹掉对比 |
| hybrid | explainer 的演示＋总结、epic/documentary 的段落推进 | 段内连续、段间可硬切；记录切换理由和理解桥梁，不让观众重新寻找对象 |

配方给倾向，不决定每镜动作。此表与镜头目的优先于历史风格卡中的“全程微动”“禁止硬切”等通用口号。静止不等于渲染冻结；用实际片段和登记的时窗区分。

### 2. 独有介质动作法则（One Native Move）
选用强调材质的路线时，在高潮或核心解释处安排一次能解释内容的「介质特征动作」；60%–75% 是常见 hero moment 位置，不强迫教学证明或档案证据迁就百分比：
- **水墨**：墨滴入水晕开、水纹荡漾散发；
- **粉笔**：板擦拂拭抹除、粉笔细碎尘末滑落；
- **剪纸/拼贴**：折痕阴影透射、纸片错层掀开；
- **工业机械**：齿轮啮合、插销卡嗒回弹、刻度表指针震颤；
- **历史档案**：朱砂印鉴落章渗透、火漆印熔压、泛黄纸张微卷翻页。
杜绝「不同风格只换了一套色板和 CSS 滤镜，运动全是千篇一律的 opacity/translate」。

### 3. 时长最大值闭合定理（Timing Max Theorem）
单镜头时长至少覆盖动作完成、画面读完和相关旁白完成三项所需的时间窗（并行发生取最大值，先后发生计入偏移）：
$$\text{duration} \ge \max(t_{action}+d_{action},\ t_{text-ready}+d_{reading},\ t_{voice}+d_{voice}+d_{pause})$$
- 阅读计时从文字完整且稳定可读时开始，不从镜头第 0 帧算。5–7 字/秒或代码 3 token/秒只能作初估，复杂关系要用实际 480px 样片复看。
- 若换音色导致旁白拉长，重新锚定词级 cue、字幕、动作与切点；先检查是否该删冗词、分段揭示或延长理解停留，不能默认把多出的时间交给环境微动。
- 一个关键词可以对应已有证据的持续可见，不必每念一个名词就新增动画。避免声音、图表和字幕同时引入三个新重点。

## 母题与复现（v4.3.0，方法论吸收 mexicat/pdoom-video，MIT）

creative-brief 在「贯穿示例」之上升格为 treatment 六件套，写进 `research/creative-brief.md`：

1. **母题表**：贯穿对象 + 它在每章"变成什么"（一根线：写完词变成曲线、曲线变成图表、图表弯成物件）。贯穿对象"做事"是底线（SKILL 硬性原则）；母题表把它升级为叙事装置——每次变形都是一个章节的记忆点，结尾回收母题收束。
2. **复现模板变奏**：同一版式复现 ≥2 次时必须变奏升级（同构句式每次加码、同模板换参数变体），禁止原样复读；第 N 次出现要在幅度/密度/色彩其一上明显超过第 N−1 次。
3. **一色一瞬**：主色板之外的稀有色只归一个瞬间所有（全片 ≤2 处、单处 ≤3s），用来钉全片唯一的高光时刻；稀有色复用即贬值（判例与自检见 aesthetic-rules G1）。
4. **明暗节奏**：相邻章节在明底/暗底之间交替，长片至少一次反差切换（全暗片读作没换景）。
5. **循环闭环**（可选，抖音自动循环场景的完播杠杆）：尾帧回收开场构图，交付时 probe 首尾帧差登记 `loop: true`；平台循环播放时观感"看不出头"。
6. **冷面注脚**：正经画面里埋一行 mono 小字冷幽默（表单字段/QC 日志/统计脚注），一幕最多一处；幽默靠事实错位，不靠表情包。

**文字进画两条纪律**（有逐字时间戳时）：提前变亮 ≤0.4s 允许、高亮永不领先人声；文字"进画"而非"贴底"——每章换一种图形化整合（写在对象上/沿路径排/被印出来/被打出来），不做全局贴底字幕复读。

## 签名转场（huashu-art-motion 方法移植，MIT）

当镜头确需介质转场时，优先**从下一个镜头或章节的签名语言里长出来**——转场同时完成两件事：告别上一段、预告下一段，观众在 0.3 秒里就知道「下一个是谁」。huashu 实测 15+19 个转场全部按此法设计、迁移测试评为「整份 skill 里最值钱、可迁移性最强的一条」。

先判断硬切/匹配切是否更清楚；需要签名转场时用以下四步：

1. **找物理过程**：问「下一个镜头/章节的世界里，什么会以什么物理方式出现、点亮、扫过？」——水墨是晕开、蓝图是图层显影、终端是扫描线逐行点亮、拼贴是纸片贴入、霓虹是电流跳接。gallery 各风格卡与 styles SPEC 的签名特征节是现成清单。
2. **用它污染旧画面**：转场前半段，新风格的过程作用在旧画面上（蓝图网格线爬上旧画面、水墨在旧画面上洇开）。
3. **新画面从这个过程的形状里露出来**：旧画面从这个形状之后才换，不从屏幕边缘擦。
4. **拍点上叠一个短暂的高亮或过冲**：落点那一帧要有整屏可见的变化；有 BGM 的片对齐 beat sheet 的落点，冲击作用在新旧两层（只冲新层会读作「声音先到画面后到」，huashu 实测量到拖拍 0.1–0.17s）。全画面级冲击的配额照 aesthetic-rules R4（全片 ≤3 处）。

配套两条：

- **开场没有上一镜可借时，让第一幅画「自己画出来」**：用该风格的作画过程开场（蓝图图框绘制、粉笔字渐写、铺沙渐显——styles 各卡的签名开场已是此法），第 0 帧不再是白纸/黑场，同时满足钩子 0.5s 判据。
- **签名转场越复杂，时长越长**：inOut 缓动两头几乎看不出变化，复杂签名转场 0.34s 只读得到 0.2s、会被读成普通擦除——按「看得见的部分」定时长（huashu 实测金箔/色带类要 0.48–0.5s）。跨镜转场挂组级独立层的工程纪律见 lessons（批 4 SceneWipe 条）。


## 多点打样

大规模制作前渲开场、最复杂中段、结尾三处真实运动片段，使用真实音色、字幕和目标尺寸。审定：能否读完、能否看懂变化、注意落点是否一致、声音和动作是否自然。首屏好看不能推导整片好看。

## 演绎三铁律（理解、注意、节奏）

1. **关键词有可见依据。** 观众听到术语、数字或指代时，能找到对应对象/变化/结果。必要时触发动作或高亮，已清楚展示的证据可以保持稳定，不逐词制造动效。
2. **留白有目的。** 阅读、比较、悬念和情绪落点允许静止与留白。记录目的、区间和离开条件；缺主体、占位空卡、旁白在解释而画面没有对应内容仍是缺陷。时长从任务测量，不把合法静止限定为两个固定档位。
3. **相机有任务。** 只为揭示空间、转移焦点或改变情绪运镜；文字、读数、代码需要稳定时停机。continuous 世界可保留克制的环境层，但 MAD 非零不是质量标准，旁白存在也不意味着相机必须移动。

`WordLitCaption` / `ChapterBadge` / `GoldenQuote` / `RecapFrame` 是可选结构件，按镜头目的使用；现成组件的微推默认值不覆盖阅读需求。配方接线见 recipes/explainer.md。

## 多轮优化

每轮先找到最弱镜头，再判断根因：事实不清、稿件不能画、状态变化不成立、主体不可信、布局或时序错误、声音问题、工程失败。先修根因，再修装饰。必要时重写稿件、图元库或整章；不要只叠效果掩盖缺陷。

修复以同内容同片段前后对比验证，同时检查相邻边界和全片回归。记录问题、决定、改动文件、重渲媒体哈希与检查范围。阻塞项清零后仍需整片运动和实际听感审查；未具备能力的检查留为not_performed。

**运动量按配方语义读，数字不定罪。** 探针给出的静止帧对、运动面积按镜头任务解释：呼吸章、结尾定帧、阅读镜头的静止是合法设计（huashu 实测 storytime 语法七成帧完全静止仍是好片——「动在节点上、静在笑点上」）；反过来「一直在动」的世界底章要防两种假活：整层低帧率换种子重洗（读作「闪」不是「活」，huashu 实测整屏 8fps 重洗的帧差比转场还大——氛围层改为位置固定、方向场随时间连续演化）和恒定微动凑活性（directing 手册既有纪律）。成片级数字用 `scripts/probe_motion_quality.py` 采样（运动面积/静止帧对/孤立跳变/最长静止），每处孤立跳变看证据拼图定性：设计内相机推拉放行，穿帮/闪烁/重洗立案。

**逐镜审计用于找问题，不用静态比例定罪。** 对 >3s 的持镜或静态占比高的镜头，逐镜核对主体是否仍承载当前句、观众是否尚在读/想、下一次状态变化是否太晚。2fps 帧差、freezedetect 和运动面积只定位疑点；细小粒子会让帧差非零，也可能低于检测阈值。两种情况都不能单独判通过或失败。

**长持镜先定功能，再定是否微动。** 换音色造成的静态长尾，要重新检查词级 cue、阅读时间、动作密度和切点。阅读/比较/情绪停留可保持真正静止；需要持续世界感的 sand 镜头可用 DustDrift / PetalFall / SandStream / PaperBreath，但只在有明确理由时用。合法静止和设计内硬切在分镜与 beat sheet 记区间、理由，验收时逐条对账；实际渲染冻结、无内容空等、意外跳变不能靠补写“有意”免责。

**审片查逻辑和数字口径，不只查画面。** 反向轮的事实核查升级三条判例（huashu 实测抓到、画面全部完美但内容错）：①倍数表述——「涨了 9 倍」应为「涨到原来的 9 倍」，且倍数要能从画面上的数算出来；②图表不撒谎——柱一律从 0 起，轴不从 0 起必须明写「纵轴未从 0 开始」，单位/来源/「示意数据」角标逐镜核（真实数据不许出现示意角标）；③口径一致性——同一数字在不同镜头的值必须对得上（日 K 终点 vs 月线终点各说各话的实测案例）。教学片的数据标注参照 `cards/data/` 图表卡的既有参数表。
