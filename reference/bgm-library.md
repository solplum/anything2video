## 使用约定

1. 双曲结构允许：贯穿垫底（G1 型）+ 收尾换曲（G5/G3 型）——换曲点放在章节卡或压黑段。
2. 程序编曲（score_gen 三档）保留为兜底：唯一优势是段落=句边界自动对齐 + 可复现；质感要求高的片优先用本曲库。
3. 新曲入库纪律：试听定性 → 登记本表（曲名/ID/时长/气质/映射）→ 许可确认（Mixkit 免费许可类直接入库，其他许可逐案核）→ **入库即跑** `uv run python scripts/bgm_analyze.py assets/audio/bgm/<新曲> --out-dir assets/audio/bgm/profiles` 生成客观层档案；主观层标注回写（`human_reviewed=true`）后方可用作机制侧切点真值。
4. **主题反查（2026-10-11 总定案）**：做片时视频题材/文章/风格已定 → 按「视频题材 × 落位功能（钩子/垫底/hero/收尾）」读 profiles 逐段 `theme_tags`/`func` 提名命中曲与段落（可跨多曲），出音乐编排表（哪段曲、曲内进出点、视频落位、crossfade）给用户拍板。题材轴词表（受控，可扩）：科技未来/人文叙事/情感抒情/国风古典/悬疑紧张/欢快活力/史诗宏大/沉静冥想/商业品牌/知识科普。用户自加曲的题材由**用户亲选**；skill 自带曲池可由主控按实战映射+结构数据定标（`theme_annotations.by` 记录来源）。**用户曲库优先权重**：用户自加曲有合格题材命中即必占提名首选，曲池曲/程序编曲只作补充位；无命中按片型分工回退、不硬凑（细则见 `bgm-bakeoff.md` 选曲交互规范）。
