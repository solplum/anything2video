# 空间长镜

沿空间关系移动镜头，在连续观看中交代结构与变化。

本页是整片路线，接在 [统一生产流程](../production-workflow.md) 的对应阶段；授权、工程和终检仍只按 [统一生产契约](../production-contract.md)。不重复询问已确定的风格、文案、画幅与音乐，不新设审批门。

## 输入

- 空间布局、主体尺寸和观察节点
- 投影类型、相机路径与可用渲染依赖

## 独立工序与产物

1. **搭空间灰模**：主体与观察节点的空间关系。
2. **先走完整镜头**：低成本完整机位预演与遮挡检查。
3. **加入材质与信息**：实测帧成本后增加光照、标注与细节。

## 先走通空间，再做材质

画出世界坐标、观察节点、主体朝向与焦点，先用灰模看完整相机路径。选中 `studio-oneshot` 才按其 SPEC 配置实际 three.js 依赖；`isometric-city` 是 CSS 等轴，`PageCam` 是 2.5D 大画布，不把它们误报为相同实现。

重要节点的接近、停留与离开必须服务理解。不能只靠静帧判定运镜平滑，也不能因“一镜到底”的名字强迫镜头永不暂停。先实测一段的帧成本，再增加材质和灯光；性能修正不能悄悄删掉叙事对象。

[纸雕灯影](treatments.md#paper-lightbox) 需要平行纸层、孔洞、背光与层间影；[版画长镜](treatments.md#printed-longtake) 需要世界坐标固定的刻线。二者是待实现的独立材质子路线，不归并成普通立体书或影棚换色。

## 专项检查

- 运动中焦点仍可跟随，重要物体无遮挡。
- 2.5D 与真正 3D 的实现方式明确，不凭名称假定。
- 按实际宽高比重排镜头，标签可读且无穿模。

## 接回交付

专项观察写回既有 visual / motion / teaching / audio 审查，保留媒体与源码哈希；仍需整片播放、完整听取及既有 QC。路线目录、静帧、类型检查和计划校验均不证明本片已经通过。无实际检查就记录 `not_performed`。
