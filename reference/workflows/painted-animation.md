# 绘画动画

先确定绘画语言，再设计笔触、材质和画内运动。

本页是整片路线，接在 [统一生产流程](../production-workflow.md) 的对应阶段；授权、工程和终检仍只按 [统一生产契约](../production-contract.md)。不重复询问已确定的风格、文案、画幅与音乐，不新设审批门。

## 输入

- 画风参考与可用图元或分层素材
- 画面要表达的情绪、信息和具体动作

## 独立工序与产物

1. **确定一帧**：定稿构图、主体、材质和信息区。
2. **拆层与运动**：每层选择代码/分层素材/生成视频的实际方法。
3. **验证连续画面**：最难动作、材质稳定性及前后镜头的短样片。

## 一帧与运动分开解决

按 [AI 素材 SOP](../ai-frame-sop.md) 在每个镜头选择 A 代码、B 分层素材、C 生成动态、D 混合。四种方法不是质量排名，也不是整片必须统一使用的配置。先让定稿帧具有正确构图与材料语言，再决定哪些东西必须真的动。

程序笔触用固定 seed；分层素材保留原画布坐标、裁剪框和接触影；生成动态登记实际媒体哈希、身份和连续性检查。首尾相同输入图不保证输出无缝，需要实查接缝。镜头中的年份、图解和字幕仍由代码负责。

已有铜版雕刻可复用随形排线，但目前是 12 秒无声材质研究，不会自动画出任意主题的完整影片。青花显影已接入独立的 [porcelain-reveal 原型](../../styles/porcelain-reveal/SPEC.md)：原创莲塘双鱼、多点渗化、湿边积色与收尾定色，含独立横竖屏布局。它沿用 [cobalt-reveal 子路线](treatments.md#cobalt-reveal)，仍是手动 kit；更换主题需原创/授权画作并重验遮罩覆盖、信息留白与连续动作，不代表标准 CLI 或成片认证。

## 专项检查

- 笔触随形塑造对象，不用纹理覆盖替代画面设计。
- 材质稳定，动作与叙事有关而非全屏无意义微动。
- 生成素材逐项审查，精确文字和事实仍由代码负责。

## 接回交付

专项观察写回既有 visual / motion / teaching / audio 审查，保留媒体与源码哈希；仍需整片播放、完整听取及既有 QC。路线目录、静帧、类型检查和计划校验均不证明本片已经通过。无实际检查就记录 `not_performed`。
