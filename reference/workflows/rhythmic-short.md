# 节奏短片

围绕关键语句与能量起伏组织短片，而不是不断随机转场。

本页是整片路线，接在 [统一生产流程](../production-workflow.md) 的对应阶段；授权、工程和终检仍只按 [统一生产契约](../production-contract.md)。不重复询问已确定的风格、文案、画幅与音乐，不新设审批门。

## 输入

- 少量核心信息与可读的短文案
- 已选择的音乐/节拍合同；也可明确无音乐

## 独立工序与产物

1. **定信息与能量曲线**：核心词、证明拍与结尾回收。
2. **先做节奏预演**：字词、动作和切点的低成本完整样片。
3. **细化视觉与声音**：阅读停留、动效词汇和音画落点的统一时间轴。

## 节奏组织与接力剪辑分开

先定一句主张、关键证明和结尾回收，安排能量变化与必要阅读。已有 pdoom 卡片、`WordRelayGeometry` 和 typography/rhythm 卡库提供镜头词汇，不提供本片的论据或整体节奏。原理讲不清时应先修内容，不能以更多闪切代替。

有旁白按词锚定，有音乐按实测拍点或已声明的编曲合同，明确无音乐时仍可按动作与阅读编排。不要为套节拍强行加音乐。普通硬切和合法定帧继续可用。

只有选了 `editingMode: match-cut-beat-relay` 才读取 [匹配剪辑合同](../match-cut-beat-relay.md)，且只约束声明的接力切点。其他七条路线也能用它；它既不是第九个风格，也不是本路线必选项。先看低成本预演，最后听看实际编码的整片。

## 专项检查

- 不是每一拍都塞新信息，关键句保留阅读时间。
- 词与动作有意义联系，字形不妨碍理解。
- 只有明确选用接力剪辑时才启用其合同，不强制全片卡拍。

## 接回交付

专项观察写回既有 visual / motion / teaching / audio 审查，保留媒体与源码哈希；仍需整片播放、完整听取及既有 QC。路线目录、静帧、类型检查和计划校验均不证明本片已经通过。无实际检查就记录 `not_performed`。
