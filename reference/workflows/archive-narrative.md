# 档案叙事

围绕原件、照片和地图推进故事，让证据出现在画面中。

本页是整片路线，接在 [统一生产流程](../production-workflow.md) 的对应阶段；授权、工程和终检仍只按 [统一生产契约](../production-contract.md)。不重复询问已确定的风格、文案、画幅与音乐，不新设审批门。

## 输入

- 可追溯的原件、历史照片、地图与许可
- 事件时间线、证据强度和未知事项

## 独立工序与产物

1. **整理档案证据**：research/archival-rights.json 与 claims/assets 绑定。
2. **打样原件阅读**：原件全貌→局部证据→上下文的可读镜头。
3. **串联证据叙事**：事件与证据交替，不以生成图冒充档案。

## 原件先于视觉效果

按 [documentary](../../recipes/documentary.md) 整理原件与权属；法律期限和馆藏条款要核查实际作品与使用地区，不能直接套用历史示例年份。来源登记不证明许可成立。每个镜头从全文/全图进入局部，再返回事件上下文；比例、裁切和高亮不能改变原件含义。

运行时仍为 `promo` / `explainer` / `epic` 之一，**不可写 `recipe: documentary`**。路线选择放在 `research/production-route.json`，实际镜头接 [RostrumStage](../../template/src/common/kit/RostrumStage.tsx)。使用灯台、拼贴或月窗只是外观选择，并不自动获得档案素材和事实。

《命》等片只作为 [历史台账](../style-ledger.md) 的叙事经验；铜版雕刻是无声材质研究，档案灯台仍是本地试验。须重新验证本片连续运动、文字阅读与声音。

## 专项检查

- 放大的是同一原件，局部仍保留上下文。
- 年份、引文与图像身份逐项核对。
- 足够停留看原件，生成重现须明确标为示意。

## 接回交付

专项观察写回既有 visual / motion / teaching / audio 审查，保留媒体与源码哈希；仍需整片播放、完整听取及既有 QC。路线目录、静帧、类型检查和计划校验均不证明本片已经通过。无实际检查就记录 `not_performed`。
