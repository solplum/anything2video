适用: 讲 LLM/生成式 AI 原理的教学片；prompt 演示；任何"模型在预测"的镜头
时长: 一句 prompt 3–6s
能量: 中
标签: typography

## 意图
讲"大模型逐 token 生成"最难的点是把抽象采样变成可见事件。本卡把打字
升级成**可视化采样**：每个 token 被打出的瞬间，头顶闪出"我当时还在纠结
哪些候选"的分布条——当前 token 高亮居首，落选者带着概率陪跑。观众第一
次"看见"采样这个动作。落选候选写成梗，是本卡的灵魂。

## 动效核心
- 主文本：mono 字体打字机逐 token 打出（字级时间戳钉帧）+ 尾光标闪烁
- 分布条：每个 token 出现瞬间，头顶 0.3–0.5s 闪现 4–5 条横向候选条——
  当前 token 高亮色 + 概率数字，落选者灰阶；条长 ∝ 概率， easeOutCubic
  展开、到时整体淡出
- 行尾：光标停 2f → ⏎ 符号弹入 → 下一镜触发（flash/zoom/整屏推进落
  downbeat——"回车即引爆"是本卡的章节缝合用法）
- 变体三拍（同一版式换参数，pdoom 三连 prompt 语法）：压迫版（背景同心
  环收紧）/ 困住版（前景竖条逐拍合拢）/ 哀求版（打完后字符间距缓慢漂散）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 候选数 | 4–5 条 | <3 不成"分布"，>6 读不完成了菜单 |
| 闪现时长 | 0.3–0.5s easeOutCubic | 常驻=跟主文本抢读（命门），全卡只许闪现 |
| 主 token 概率 | 候选中最高（0.4–0.7 区间） | 概率加和不必=1，但主 token 必须居首 |
| 条形字号 | ≥ 帧高 3%（aesthetic-rules Q11 辅助线） | 概率数字比候选词再小一档 |
| token 节奏 | 钉字级时间戳 | 无时间戳时 6–9f/token 匀速兜底 |
| 回车引爆 | ⏎ 后 2f 内触发转场 | ⏎ 与转场间隔 >0.3s 读作两个动作 |

## 声音
每 token 打字声（轻，ui-tone 级）；落选条闪现不配音；⏎ 一声 enter 重击
+ 下一镜的引爆音对齐同一帧。

## 已知坑
- 候选词必须写**具体的梗**（"eat 0.44 / delete 0.21 / train on 0.18"）——
  占位词读作假 UI，梗才是本卡的记忆点（梗要服务本片主题，不是通用彩蛋）
- 分布条位置逐 token 跟随其头顶，但避免超出安全区——末 token 的条向下翻
- mono 是纪律（token=等宽机器语感），比例字体会把"逐 token"读成"逐词"
- 与 ai-stream-response（流式回复 UI）分工：那张卡演"AI 在回复我"，
  本卡演"AI 在猜词"——同片不同镜，不要混用
