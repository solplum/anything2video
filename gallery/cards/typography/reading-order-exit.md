name: reading-order-exit
一句话: 阅读序逐词退场——句中各词按阅读顺序每 2f 一个依次上浮 0.12em 淡出（每词 5f），只留 hero 词/图标钉在原地，下一招直接从幸存者身上起手
适用: 从陈述句中"拎出"关键词的前置动作：退到只剩 hero 词再接形状匹配切/推近；温和清场后再进安静的 UI 段
时长: 5 词句约 13f 清完（@30fps）；松散变体每词 10f、间隔 3f，共 16–22f
能量: 低中
标签: typography
来源: 手法研究自 cinetic (MIT, Leonxlnx)；配方说明独立整理，尚无本仓实现/演示

## 意图
库内的词级入场词汇很厚（打字/滚升/锁定），退场几乎只有"整段淡出"。
本卡补上逐词退场：句子像被读完后收走——按阅读顺序退，观众的目光
自然滑到唯一幸存的 hero 词上，退场本身完成了视线聚焦。它不是"文字
消失"，是"注意力被排序"。与 blur-slide 分工：那卡是整词模糊滑移
的单次进出，本卡是句级扫荡的注意力调度。

## 动效核心
- 逐词窗口：词 i 的退场帧 = 起点 + 2i；每词 5f 内完成
  （上浮 0.12em ≈14px + 透明度渐隐走平滑曲线 + blur 0→4 消散）
- 透明度禁 ease-in 曲线（首帧跳 55% 的闪消感），必须平滑渐隐
- hero 词/图标全程钉在原位零动画——它的"不动"就是聚焦本身
- 衔接：末词清完 ≤3f 内下一招起手（推近/形状匹配/换底），聚焦
  不留真空
- 松散变体（calm 版）：各词沿自身符号方向漂离 10–20px + ±2° 微
  旋转，先褪向底色再淡出，每词 10f、间隔 3f——用于不急着聚焦的
  柔和交接
- Remotion 要点：逐词 opacity/translate 由词索引查表（纯函数）；
  blur 用恒定模糊拷贝交叉淡化或直接轻微 text-shadow 衰减，避免
  动画 filter 阶差

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 每词时长 | 5f | <4f 读作逐个闪灭；>8f 全句清得拖沓 |
| stagger | 2f（阅读序，可 1–3f） | 完美等距是刻意的"点名收走"，加抖动反而乱 |
| 上浮量 | 0.12em | 上浮给"读完收走"的轻盈；下沉读作删除 |
| hero 钉位 | 零动画 | hero 也微动则聚焦失败 |
| 衔接窗口 | 末词清完 ≤3f | 隔 >6f 聚焦冷却，下一招重新起热 |
| 松散变体 | 10f/词、间隔 3f、±2° | 用于 calm 段；紧凑版与它不可混排 |

## 已知坑
- 讲解型字幕紧接相机运动时禁用：字幕该整段 13f 淡出并在镜头启动前
  0–28f 收完，逐词退场会跟镜头抢注意力
- 退场词数 ≤6：逐词点名是仪式，词多就成直播弹幕消失
- 金句/payoff 行禁用任何退场——它该被完整读完后由后续镜头接手
- 与 title-demote-to-label 分工：那卡是标题降级变小驻留，本卡是
  其余词退场只剩 hero 驻留；都是"减法"，但一个减字号一个减词数
- 参数为 cinetic 出厂推荐值（60fps 折算 30fps），首次实战须回验
