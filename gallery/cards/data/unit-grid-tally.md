## 意图
"3/10"写在纸上只是分数，画成十格里亮起的三格才被"看见"。本卡把
计数与点阵焊死在一起：数字永远等于已亮格数×单位值，两者不可能说谎
不一致；对角波填充给"在数"的过程感，最后一格（往往是"你"）用
accent + 脉冲落锤。与 particle-sand-fill 分工：那卡是粒子堆积的
质感型填充，本卡是格子阵的计数型填充——每格是可点名的份额。

## 动效核心
- 网格：n×m 个 14–20px 圆角方块，底色用灰线轨色（C.line 级），每格
  代表固定单位数；格距紧凑读作"一块"，格距拉开读作"一群"（按
  语义选）
- 填充波：格 (r,c) 的入场时刻 = 起点 + stagger(r+c, 行列和−1)，
  总铺开 15f ease-out；单格透明度 4f 渐入 + 缩放 0.6→1 微 spring
- 计数器：数值 = 已亮格数 × 单位值，按帧取整（tabular 数字防跳动），
  与网格永远同一帧同步——计数器不许独立缓动
- 落点格：承载论点的那格（末格/代表"你"的格）落位时打 accent 色 +
  1.15× 脉冲（attack 1f、τ≈4f 衰减），可再给 2px 外扩描边一帧
- hold：全阵 +2% 呼吸推近 ≥18f，旁白在此读数
- Remotion 要点：已亮格数 = 按帧算 stagger 表（纯函数），计数与
  格阵共享同一数组长度派生，禁两套时间线

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 格尺寸 | 14–20px | <12px（竖屏）点不清；>28px 阵列读作马赛克装饰 |
| 对角波总长 | 15f | >25f 数过程拖沓；<8f 失去"逐格"可数感 |
| 单格入场 | 4f 淡入 + 0.6→1 spring | spring 过冲>10% 读作 Q 弹，证数感崩 |
| 计数同步 | 已亮格×单位，逐帧取整 | 计数器先行/滞后一帧都会被暂停帧抓住 |
| accent 脉冲 | 1.15×、attack 1f τ4f | 只给承载论点的 1 格；多格 accent 稀释 |
| hold | ≥18f + 2% 推近 | 计数结束即切走观众读不完数 |

## 已知坑
- 有效位数多的精确值禁用（格子无法诚实地表达 7.3%）：取整格数+
  文字注明误差，或换图表卡
- 格子必须与单位严格对应（1 格=1 单位或整十单位），"一格≈一点"的
  模糊对应会在暂停帧露馅
- 竖屏 9:16 下方格 <12px 时改行列式条形或减少总格数
- 与 hatch-depth / gauge-readout-moves 分工：那两个表达"程度/仪表"，
  本卡表达"计数/份额"；同片可共存但同一段落别堆两种计量语言
- 参数为 cinetic 出厂推荐值（60fps 折算 30fps），首次实战须回验
