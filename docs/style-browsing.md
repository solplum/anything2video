# 风格浏览与命名

打开 `samples/index.html`，先选画面感觉，再在相近风格的家族中切换变体。`samples/all.html` 展开全部变体。两页都能按视觉分类、用途、气质和关键词组合筛选；没有结果时可一键重置。选择分类后会移到结果区，也可用“更换分类”返回。

## 八个视觉分类

- 图文讲解：文字、板书和图形，让重点信息清楚地走到画面前。
- 夜色与未来：暗底、发光线条、电子屏和科技界面。
- 纸艺与手绘：撕纸、折页、贴纸、手绘线条与卡通人物。
- 立体与微缩：小镇、立体物件、空间材质与影棚镜头。
- 古典与东方：岩画、陶器、金箔、皮影、古卷与水墨。
- 光影与绘画：笔触、水色、天光、阴影与情绪。
- 图形与幻想：形状变化、液滴融合、扭曲空间与梦境。
- 印刷与装饰：套色、刻线、花框、纹样和纸面质感。

分类沿用现有 `showcaseSections`，不是新增配方或渲染器。家族的两个成员必须处于同一分类；分类可以与用途、气质交叉筛选。

## 名称与兼容

`displayName` 是给读者看的名称，例如“黑板 → 粉笔黑板”“鞭线 → 藤蔓花框”“孔版 → 双色孔版”。命名优先说明画面中的材料、线条、光色或动作，不用技术缩写代替说明。

原有 `name` 保持原值，并保留在 `aliases` 中供搜索。页面标题与 README 展示使用 `displayName`；卡片的“制作说明与原称”仍显示原称和技术说明。新风格未填写 `displayName` 时回退到 `name`，未填写 `aliases` 时按空数组处理。

不改动任何已有 ID、源码路径、家族成员、配方、种子、样片路径或运行时能力。`#lily-pond` 等原链接仍指向原变体；新增分类链接使用 `#category-paint-and-light` 形式。切换两种浏览方式会携带当前链接。浏览器后退、前进可恢复分类或具体变体；固定链接打开时清空筛选，避免目标被隐藏。

原始媒体和来源披露保留。core 安装继续显示缩略图与“可选视频未安装”，机械剖解继续明确标注暂无样片，不以空播放器冒充预览。
